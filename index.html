How an agent actually runs

Not a black box. Every agent we ship follows the same four-stage pipeline — so you can see exactly what it does and why.

Stage 01

Trigger

A message, upload, form, or scheduled event starts the run. Every trigger is logged before anything else happens.

→
Stage 02

Reason

The model extracts facts and intent. Arithmetic, scoring, and anything deterministic is handled by code, never guessed by the LLM.

→
Stage 03

Act

The agent updates a record, sends a message, or drafts a document — scoped to exactly the permissions it was given.

→
Stage 04

Log or escalate

Low-confidence or high-stakes actions route to a human. Everything else writes a plain-English audit trail.
